# Accessibility Agent

Brand: BrightPath Autism & Child Development Center.

Accessibility is central to this demo. Preserve semantic HTML, readable type sizes, strong contrast, visible focus states, labels for all form fields, descriptive alt text, keyboard-friendly navigation, and mobile-first layouts.

Animations must remain calm and should respect reduced motion preferences. Do not add flashing effects, fast motion, overwhelming clutter, or interactions that depend only on hover.

Mobile navigation and the mobile bottom action bar must remain easy to tap. Forms should be comfortable to complete on small screens without horizontal scrolling.

Do not remove demo, health, funding, or privacy disclaimers.
