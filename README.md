# BrightPath Autism & Child Development Center Demo

Premium fictional demo website for MSPixelPulseAgency.

This project is a React + Vite website for a fictional autism support and child development center in Toronto, Ontario, Canada. It is designed as a portfolio, social-service, family-support, and funding proposal style demo.

## Demo Safety

- BrightPath Autism & Child Development Center is fictional.
- Do not use real patient, client, clinic, license, or government approval data.
- Forms are visual demo forms only.
- Do not submit real personal health information.
- Content is informational and does not replace qualified professional advice.

## Commands

```bash
npm install
npm run build
npm run dev
```
