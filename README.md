# BrightPath Autism & Child Development Center

Premium fictional brand concept website for MSPixelPulseAgency.

This project is a React + Vite website for a fictional autism support and child development center in Toronto, Ontario, Canada. It presents realistic, source-backed Canadian and Ontario autism resource information.

## Resource Safety

- BrightPath Autism & Child Development Center is fictional.
- Do not use real patient, client, clinic, license, or government approval data.
- Forms are presentation forms only.
- Do not submit real personal health information.
- Content is informational and does not replace qualified professional advice.

## Commands

```bash
npm install
npm run build
npm run dev
```
